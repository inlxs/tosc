**Terrain Oscillator** turns real places into wavetables. Pick anywhere on Earth, and its terrain becomes the sound.

### Download
| System | File | Formats |
|---|---|---|
| Windows 10/11 | `TerrainOscillator-…-Windows.zip` | VST3, CLAP, Standalone |
| macOS 11+ (Apple silicon + Intel) | `TerrainOscillator-…-macOS.zip` | AU, VST3, CLAP, Standalone |
| Linux x86_64 | `TerrainOscillator-…-Linux.tar.gz` | VST3, CLAP, Standalone |

Each download contains an `INSTALL.txt` with where to copy the files.
macOS builds are not notarised yet: run the one-line `xattr` command from `INSTALL.txt` after copying.
