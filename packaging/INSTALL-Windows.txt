Terrain Oscillator - Windows
An Okllo instrument - https://okllo.com - https://github.com/inlxs/terrain-oscillator

Standalone
  Run "Terrain Oscillator.exe". Choose audio output and MIDI input under Options.
  Windows may show a SmartScreen warning because the app is not code-signed yet:
  click "More info" -> "Run anyway".

Plug-ins (Bitwig, Ableton Live, Reaper, FL Studio, Cubase, Studio One ...)
  VST3: copy the folder "Terrain Oscillator.vst3" to
        C:\Program Files\Common Files\VST3
        (or, without admin rights: %LOCALAPPDATA%\Programs\Common\VST3)
  CLAP: copy "Terrain Oscillator.clap" to
        C:\Program Files\Common Files\CLAP
        (or %LOCALAPPDATA%\Programs\Common\CLAP)
  Then rescan plug-ins in your DAW. It appears under the maker "Okllo".
  Ableton Live uses the VST3. Bitwig: prefer the CLAP.

Requires Windows 10/11 64-bit with the Microsoft Edge WebView2 runtime (already part of Windows 11
and current Windows 10). An internet connection is needed to load maps and elevation; playing saved
tables works offline.
